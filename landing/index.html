⚡ Produtividade imediata

Rotinas repetitivas viram um comando: abrir, buscar, preencher e confirmar — sem escrever uma linha de código.

🔒 Privacidade por padrão

Sem telemetria. A chave de API e os dados ficam na sua máquina; nada é enviado sem o seu comando.

🧩 Qualquer IA OpenAI-compatible

DeepSeek V4, GPT e outros: você escolhe o modelo e a URL nas configurações — sem amarras.

🌐 Open source e auditável

Código aberto no GitHub e gratuito para sempre. Sem pegadinha, sem assinatura escondida.

Segurança não é um extra.
É o padrão.

Construímos a Athena para ser transparente por natureza. O que ela faz com os seus dados está escrito — e é pouco.

Zero telemetria

Nenhum dado é coletado em segundo plano. A extensão não tem analytics nem rastreadores.

Chave no seu navegador

A chave de API fica no chrome.storage.local — nunca sai da sua máquina.

Conteúdo só no comando

A página é enviada à IA apenas quando você digita um comando — e direto ao provedor, via HTTPS.

Sem código remoto

Tudo é estático e auditável (Manifest V3). Leia o código no GitHub se quiser.
